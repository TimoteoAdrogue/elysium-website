Design and technology.

Design direction for the elysium.cc rebuild, step 1 of the brief of 3 October 2026. Every value on this page is live: ratios are measured from this stylesheet at load, springs run on anime.js 4.5.0, and Chart A reads the §8 figures from its own tables.

01 / Palette

One ground, one accent, and red kept for the flag.

03 / Grid

12 columns to 1440 px, drawn on the page.

Gutters run clamp(16px, 4vw, 64px). Hairlines sit on the column edges (every third one below 768 px), node dots mark where a section rule crosses them, and hatched corners mark where each section starts. No element on the site is boxed: groups are made with space and hairlines, and scrolling regions fade at their edges through mask-image.

04 / Motion

3 springs, 3 curves, 4 durations, one clock.

69 archive pieces and 22 named clients, counted bar by bar.

07 / Decisions

4 calls to make before step 2.

Each one changes what step 2 builds. Everything else on this page follows the brief as written.

  1. 1 · Wordmark on dark

    assets/wordmark.png is black on transparent: on --void it measures 1.04:1 and disappears. A keeps the file and its rendering untouched on a light pill (in the nav above). B renders the same file through CSS invert(1): the file stays as it is, but the mark shows white, which the brief counts as a recolour.

  2. 2 · JS budget

    The anime.js 4.5.0 ESM bundle is 40.9 KB gzipped and Lenis 1.3.26 is 5.4 KB: 46.3 KB before any site code, over the 45 KB cap. Fitting the cap means tree-shaking anime down to the functions used, which takes one bundler run (esbuild, output vendored, no runtime dependency). That adds a build tool, so it needs your yes; the alternative is a cap near 55 KB.

  3. 3 · Charts on --void

    --accent-fill reaches 3.06:1 on --void and 2.94:1 on --raised. Charts and bars therefore stay on --void sections; the timeline and the Sierra Leone map follow the same rule.

  4. 4 · Missing case screenshots

    assets/work holds no screenshot of the WIPO Global Awards or Award Force API dashboards. Step 2 builds that case without an image and adds a CONFIRM row, as the brief directs.
